# PrefireTemplateSupport

Dependency-free template support modules for Prefire's generator:
`PathKit`, `Stencil`, and `StencilSwiftKit`.

This is a fresh Elklete repository containing the precise production sources
needed by Prefire. It preserves the Stencil language and Swift-oriented filters
used by custom `template_file_path` templates without resolving upstream
test-runner or Git-hook dependencies. See [UPSTREAM.md](UPSTREAM.md) for exact
source provenance and [Licenses](Licenses) for retained notices.
